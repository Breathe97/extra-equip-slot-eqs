# extra-equip-slot-eqs 额外的装备栏

> 这是一个为饥荒联机版打造的轻量扩展模组，让角色拥有额外的服装、护符、背包和腰包装备槽。

📦 Steam 创意工坊：[额外的装备栏](https://steamcommunity.com/sharedfiles/filedetails/?id=2946486855)

## ✨ 功能简介

- 🧢 **头饰栏** — 用于装备非护甲的头饰类物品（花环、牛帽、眼球伞等）
- 🧥 **服装栏** — 用于装备服装类物品（雨衣、背心、花衬衫等）
- 🔗 **腰包栏** — 用于装备腰包类物品（指南针）
- 📿 **护符栏** — 用于佩戴护符类物品（重生护符、建造护符等）
- 🎒 **背包栏** — 用于装备背包类物品（背包、猪皮包、坎普斯袋等）
- 🗑️ **吞噬槽** — 装备栏最右侧的"审视自我"头像兼作垃圾吞噬槽：拿起任意物品拖到头像上会提示"吞噬"，左键点击即可销毁该物品
- 🤖 **智能识别** — 未手动适配的物品会根据标签或属性自动分配到合适的槽位
- ⚙️ **可配置** — 可单独开启或关闭各个额外装备栏及自动识别功能
- 🛠️ **兼容修复** — 修复了寄居蟹隐士、重生护符、建造护符折扣、指南针 HUD、容器堆叠、复活背包重开等兼容性问题

## 📋 默认装备组合

```text
武器 + 护甲 + 头盔 + 头饰 + 服装 + 腰包（指南针）+ 护符 + 背包
```

## 🧭 使用方法

1. 安装模组后进入游戏，额外装备栏会自动生效。
2. 你可以在模组设置中控制各个额外槽位是否启用。
3. 对于未适配的物品，模组会优先尝试自动识别并分配到合适的位置。
4. **吞噬垃圾**：在物品栏里拿起任意物品（拖到光标上），移到头像上会提示"吞噬"，左键点击即可将该物品彻底销毁（整组销毁）。没拿物品时头像仍是原版的"审视自我"。

## 🖼 贴图渲染逻辑

模组不干预游戏原版的贴图渲染流程。物品分配到额外装备槽后，其 `onequipfn` 由游戏引擎自动调用，渲染逻辑由物品自身的 build/symbol 决定。

### 实时刷新

装备或卸下物品时，模组会通过 `RefreshEquipOverrides` 自动重新渲染对应插槽，确保新增槽位的贴图正确显示。该机制同时处理头部和身体/背包两个区域的刷新。

### 渲染修复

部分物品的 build 名或 symbol 名与 prefab 名不一致（如 `sunkenchest` → `swap_sunken_treasurechest`）。`FIX_SYMBOL_BUILD` 例外表在渲染前修正这些映射，确保物品在额外的装备栏上正常显示。

### 槽位分配

所有物品的槽位分配在 `InitPrefab` 中通过 `AddPrefabPostInitAny` 完成：

1. 开启「强制装备栏分配」时，检查 `FORCE_SYMBOL_HEAD/BODY/BELLY/NECK` 强制槽位映射表
2. 原手持物品 → 检查 `SYMBOL_WAIST` 腰包栏
3. 原头部物品 → 检查 `SYMBOL_HAT` 头饰栏
4. 原身体物品 → 依次检查 `SYMBOL_NECK`（护符）、`SYMBOL_BACK`（背包）、`SYMBOL_BELLY`（服装）
5. 开启自动识别后，根据标签（`amulet`/`backpack`/`candybag`）或组件属性（`waterproofer`/`insulator`/`rainimmunity`）智能分配
6. 最终渲染时查询 `FIX_SYMBOL_BUILD` 例外表，修正 build/symbol 不匹配的物品（如沉底宝箱、独奏乐器）



## 🛠 兼容性修复

| 修复项 | 说明 |
|--------|------|
| 🦀 **寄居蟹隐士** | 适配服装栏，使其能正常接收/拒绝外套类物品 |
| 💀 **重生护符** | 劫持 `onenter` 状态让原版从 NECK 槽查找护符，正确移除并销毁 |
| 🔨 **建造护符合成折扣** | 劫持 `GetEquippedItem` 回退查询 NECK → BODY |
| 🧭 **指南针 HUD** | 监听腰包栏的装备/卸下事件，正确开关指南针 HUD |
| 📦 **容器堆叠** | 服务端 `GetNextAvailableSlot` 兜底遍历所有扩展槽位，按「可堆叠→空位」顺序查找 |
| 🖥️ **服务端溢出容器** | `GetOverflowContainer` 覆盖所有扩展槽位的打开容器 |
| 🖥️ **客户端溢出容器** | `inventory_classified` 的 `GetOverflowContainer` 优先返回有空位的容器 |
| 👻 **鬼魂复活** | 大门/传送门复活后自动重新打开背包容器 |
| 🌈 **光谱背包** | 检测已变色的光谱背包，装备时使用 `swap_body_tall` 符号正确渲染 |
| 🎨 **渲染修复** | 装备/卸下时自动刷新新增槽位贴图，修正 build/symbol 不匹配的物品显示 |

## ⚙️ 配置选项

| 选项 | 默认值 | 说明 |
|------|--------|------|
| 头饰栏 | 关闭 | 是否扩展头饰栏 |
| 服装栏 | 关闭 | 是否扩展服装栏 |
| 腰包栏 | 关闭 | 是否扩展腰包栏 |
| 护符栏 | 开启 | 是否扩展护符栏 |
| 背包栏 | 开启 | 是否扩展背包栏 |
| 自动识别服装 | 关闭 | 有防水/保暖属性的物品自动归入服装栏 |
| 自动识别护符 | 开启 | 有 `amulet` 标签的物品自动归入护符栏 |
| 自动识别背包 | 开启 | 有 `backpack`/`candybag` 标签的物品自动归入背包栏 |
| 强制装备栏分配 | 开启 | 强制修正所有物品的所属栏位到期望位置 |
| 风幻龙护身符 | 保留头部 | 是否将风幻龙护身符保留在头盔栏（关则移至护符栏） |
